# Rà soát trước khi đưa lên repo ngày 23/11/2026

- Ghép thay đổi GitHub 18aaa52 xóa patch cũ; giữ cấu hình solution đã được Visual Studio cập nhật.
- Khôi phục appsettings.example.json làm mẫu. appsettings.local.json thật được Git bỏ qua.
- Restore locked-mode và build Release trên Windows: 0 lỗi, 0 cảnh báo.
- Bộ TCP: 19 ca đạt, gồm 40 client đồng thời, phân mảnh frame, timeout và payload/phiên TV2.
- Bộ TL-01/TL-02: 24 ca đạt trên MySQL/server tạm, không sửa dữ liệu hoặc cấu hình thật.
- Giữ đúng TV1 Huỳnh Công Thủ, TV2 Võ Ngọc Bình (trưởng nhóm), TV3 Trần Mỹ Nhung;
  báo cáo Word/Excel và các đường dẫn code đã cập nhật theo phân công này.
- Schema giữ 20 bảng. Chưa triển khai các module TV2 khác, HT-02/phiên thật hoặc kiểm nhiều máy LAN.

Lệnh kiểm tra:

    dotnet restore ThuVienDAU.sln --locked-mode
    dotnet build ThuVienDAU.sln -c Release --no-restore
    dotnet run --project cong_cu/kiem_tra_tcp -- .
    python cong_cu/kiem_tra_tv2/integration.py

Kết quả TV2 chi tiết ở TV2_TL01_TL02.txt. Giao diện đã kiểm bố cục trước đó;
lần rà này tập trung mã nguồn, build, TCP, MySQL và các tệp sẽ đưa lên repo.
